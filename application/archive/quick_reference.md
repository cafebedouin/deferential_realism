# Deferential Realism: Quick Reference Card

**One-page guide for practitioners**  
**Print this. Keep it visible.**

---

## The Single Question

**"Does this constraint require active enforcement to persist?"**

- **NO** → Mountain (accept, navigate)
- **YES** → Constructed (continue below)

---

## Decision Tree

### Step 1: Enforcement Test
**Question:** What happens if enforcement stops?

- **System collapses from reality** (not punishment) → **Mountain**
- **Slow decay, coordination problems emerge** → **Rope**
- **Immediate snap-back, artificial scarcity collapses** → **Snare**
- **Nothing happens, but bureaucracy persists** → **Piton**

### Step 2: Beneficiary Test
**Question:** Who benefits from this persisting?

- **Nearly everyone involved** → **Rope**
- **Specific few at expense of many** → **Snare**
- **No one (everyone complains)** → **Piton**

### Step 3: Temporality Test
**Question:** Is this designed to be temporary?

- **YES, with explicit sunset/dismantlement plan** → **Scaffold**
- **NO, intended as permanent** → (use Steps 1-2)

## Four Categories

| Type | Definition | Response | Example |
|------|------------|----------|---------|
| **Mountain** | Natural constraint (physics, logic, biology) | Accept, conserve energy, navigate | Thermodynamics, need for water, 2+2=4 |
| **Rope** | Coordination mechanism, broadly beneficial | Maintain, improve, replace if better exists | Traffic lights, TCP/IP, meeting schedules |
| **Snare** | Extractive structure serving specific interests | Expose, resist, dismantle where possible | Rent-seeking regulations, artificial scarcity |
| **Scaffold** | Temporary support for transition | Use temporarily, dismantle when done | Training wheels, construction scaffold |

**Hybrid:** **Tangled Rope** = Rope (coordination core) + Snare (extraction layer). Reform to preserve coordination while removing extraction.

## Four Indices (Always Specify)

Every classification requires specifying your position:

### 1. WHO (Power Position)
- Powerless (no exit: prisoner, child)
- Moderate (some mobility: middle class)
- Powerful (high agency: wealthy, connected)
- Organized (collective action: union)
- Institutional (controls enforcement: state, corp)
- Analytical (external observer)

### 2. WHEN (Time Horizon)
- Immediate (< 1 year)
- Biographical (20-50 years, one lifetime)
- Generational (50-100 years)
- Historical (100-500 years)
- Civilizational (500+ years)

### 3. WHERE (Exit Options)
- Trapped (no exit visible)
- Constrained (exit costly but possible)
- Mobile (can relocate with moderate costs)
- Arbitrage (can play systems strategically)
- Analytical (observer, no personal stakes)

### 4. HOW MUCH (Spatial Scope)
- Local (one institution/community)
- Regional (state/province)
- National (country-wide)
- Continental (multi-national region)
- Global (worldwide)
- Universal (metaphysical necessity)

**Default for most individuals:** [moderate, biographical, mobile, national]

## Strategic Responses

### For Mountains:
✓ Accept immediately  
✓ Conserve energy  
✓ Navigate creatively  
✗ Don't fight gravity  
✗ Don't waste finite resources on unchangeable reality

### For Ropes:
✓ Maintain if functional  
✓ Reform if degrading  
✓ Replace if better alternative exists  
✗ Don't dismantle working coordination  
✗ Don't assume all constraints are oppressive

### For Snares:
✓ Expose beneficiaries  
✓ Resist strategically  
✓ Build alternatives  
✓ Dismantle where possible  
✗ Don't mistake for Mountains  
✗ Don't accept "just how things are"

### For Scaffolds:
✓ Use temporarily  
✓ Dismantle when purpose served  
✓ Watch for permanence drift  
✗ Don't let temporary become permanent  
✗ Don't treat all supports as permanent infrastructure

### For Tangled Ropes:
✓ Acknowledge both functions  
✓ Preserve coordination  
✓ Remove extraction  
✗ Don't throw out coordination with extraction  
✗ Don't defend extraction because coordination exists

## Detection Patterns

### False Mountain (Naturalization Fraud)
**Signals:**
- Language: "just how things are," "human nature," "economic reality"
- Specific beneficiaries gain from "natural" framing
- Historical origin date exists (not actually timeless)
- Alternative systems exist elsewhere
- Resistance to transparency about enforcement

**Response:** Challenge naturalization. Ask: When did this "natural law" begin? Who maintains it?

### Piton (Institutional Inertia)
**Signals:**
- Everyone complains but it persists
- No clear beneficiary group
- "We've always done it this way"
- Originally functional but context changed
- Bureaucratic (not power) resistance to removal

**Response:** Administrative reform, not political resistance. Build coalition around "this no longer works."

### Tangled Rope (Hybrid Structure)
**Signals:**
- Genuine coordination function exists
- But implementation extracts value asymmetrically
- Small players burdened, large players benefit
- Gap between stated purpose and actual outcomes
- Both coordination and extraction are real

**Response:** Reform implementation to rebalance, don't dismantle coordination.

## Common Errors

### 1. False Fatalism (calling Snares "Mountains")
**Pattern:** "That's just how things are / human nature / economic reality"  
**Fix:** Check beneficiaries, check enforcement, check history  
**Consequence:** Unwarranted surrender of agency

### 2. Dangerous Hubris (calling Mountains "Ropes")
**Pattern:** "We can just change the rules / work around it / negotiate"  
**Fix:** Test whether enforcement can change outcome  
**Consequence:** Catastrophic failure when reality asserts itself

### 3. Over-diagnosis (treating all inefficiency as malice)
**Pattern:** Every coordination friction = extraction conspiracy  
**Fix:** Check for clear beneficiary group; if none, suspect degrading Rope not Snare  
**Consequence:** Energy waste fighting incompetence as if it's oppression

### 4. Energy Waste (wrong battleground)
**Pattern:** Fighting either unchangeable reality or ignoring changeable injustice  
**Fix:** Classify first, then allocate energy strategically  
**Consequence:** Burnout, demoralization, failure

## When in Doubt

### High Confidence Heuristics:
1. **If you can't ignore it without dying/failing:** Mountain
2. **If removal creates immediate chaos for everyone:** Rope
3. **If specific group actively resists transparency:** Snare
4. **If it has explicit sunset date:** Scaffold

### Medium Confidence Flags:
- Mixed beneficiary patterns → likely Tangled Rope
- Claims of naturalness + clear beneficiaries → suspect False Mountain
- Bureaucratic persistence + no winners → suspect Piton

### Low Confidence → Omega Variable:
Mark as **Ω** (unresolved) and specify what information would resolve it:
- Ω_E (empirical): Need measurement/observation
- Ω_C (conceptual): Need definition/framework
- Ω_P (preference): Need value judgment from stakeholders

**Don't pretend certainty when you're uncertain.** Label the blocker, route to resolution.

## Power Scaling (Rough Guide)

**How power position affects extraction experience:**

- **Powerless:** 1.5× more extraction (trapped, limited options)
- **Moderate:** 1.0× baseline (some navigation ability)
- **Powerful:** 0.7× less extraction (strategic navigation)
- **Organized:** 0.5× less extraction (collective action)
- **Institutional:** Often net beneficiaries (extraction flows toward them)

**Implication:** Same constraint feels different at different power levels. Both experiences are objectively true.
