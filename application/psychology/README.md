# Psychological Deferential Realism: Applied Practice

This directory contains the practical application of Psychological Deferential Realism—tools, protocols, and examples for daily constraint navigation.

## Overview

Psychological DR extends [Deferential Realism's external constraint ontology](../deferential_realism_psychology.md) inward. It provides:

- **Classification system** for internal constraints (substrate, detritus, clarity fetishes)
- **Testing methodology** for determining constraint types
- **Navigation protocols** for daily practice
- **Diagnostic tools** for fractures and misattributions

## The Practice

Psychological DR is **not** a theory to believe. It's a **practice** to perform.

### Daily

**Morning (10 minutes):**
- Substrate Scan: What mountain am I fighting today?
- Edge Detection: What detritus can I test?
- Demand Check: Where am I requiring certainty?
- Membrane Check: What's trying to cross my boundaries?

**During Day:**
- Use Calibration Table for rapid classification
- Notice resistance → Classify → Navigate

**Evening (5 minutes):**
- Classification accuracy check
- Edge test results
- Membrane effectiveness

### Weekly

- Constraint Map: Mountains, Detritus being tested, Cleared detritus, Clarity fetishes, Paradoxes held
- Review calibration accuracy
- Adjust protocols as needed

### As Needed

- **Crisis Navigation**: When everything feels like it's breaking
- **Litany of the Real**: At threshold moments
- **Empty Tombs Meditation**: For historical constraint work
- **Molly Bloom Protocol**: When the ship feels fragmented

## Core Principles

1. **Clarity doesn't eliminate constraints** (it reveals orientation choices)
2. **Comfort limits ≠ biological limits** (Goggins calibration)
3. **Past constraints leave traces** (Empty Tombs)
4. **Some tensions are irresolvable** (Containment, not resolution)
5. **Attribution must be tested** (Externalist diagnostics)
6. **Boundaries are membranes** (Selective permeability)
7. **Fractures reveal structure** (Use taxonomy diagnostically)

## The Three Questions

When you encounter internal resistance:

1. **What type of constraint is this?**
   - Mountain (substrate) → Defer
   - Detritus (piton) → Test
   - Clarity fetish (certainty demand) → Drop
   - Paradox (irresolvable) → Hold

2. **Where is this constraint located?**
   - Internal or external? (Externalist diagnostic)
   - Substrate or historical? (Temporal check)
   - Pattern across contexts? (Generality test)

3. **What navigation is appropriate?**
   - Substrate → Build life around it
   - Detritus → Investigate, test edges, clear if possible
   - Clarity fetish → Act without knowing
   - Paradox → Hold both, choose frame per context

- **DBT**: Adds explicit containment protocols to dialectics

## Common Misunderstandings

**NOT:**
- "Just push through everything" (ignores substrate)
- "Accept everything as it is" (ignores clearable detritus)
- "Understand yourself perfectly" (clarity fetish)
- "Resolve all paradoxes" (containment breach)
- "Transcend limitations" (false promise)

**YES:**
- Classify accurately before acting
- Test attributions systematically
- Clear detritus when found
- Defer to substrate when found
- Hold paradoxes without collapse

## Warning Signs

**You're doing P-DR wrong if:**

1. Using classification to avoid feeling (F13: Simulated Depth)
2. Demanding certainty before testing (F07: Clarity Fetish)
3. Pushing past actual damage signals (Substrate violation)
4. Never testing perceived limits (Treating all detritus as mountains)
5. Forcing resolution of paradoxes (F19: Containment Breach)
