# Deferential Realism: Field Manual
**Quick Classification for High-Velocity Decisions**

---

## Step 1: Specify Indices (Required)

Classification without indices is meaningless. Lock in your position:

| Index | Values | Your Answer |
|-------|--------|-------------|
| **WHO** (Power) | powerless / moderate / powerful / collective / institutional | _________ |
| **WHEN** (Horizon) | immediate / biographical / generational / historical | _________ |
| **WHERE** (Exit) | trapped / constrained / mobile / arbitrage | _________ |
| **HOW MUCH** (Scope) | local / regional / national / continental / global / universal | _________ |

**If you can't specify these, stop. You're not ready to classify.**

---

## Step 2: Apply Category Tests

Run constraint through decision tree:

### Test A: Reality Enforcement
**Question:** If ignored, does the system collapse due to **reality** (not punishment)?
- **YES** → **MOUNTAIN** (Accept, route around)
- **NO** → Continue to Test B

### Test B: Coordination Function
**Question:** Does this solve genuine coordination problems? Is benefit reciprocal?
- **NO** → Go to Test D
- **YES** → Continue to Test C

### Test C: Extraction Present?
**Question:** Does this also extract value asymmetrically? Can functions be separated?
- **NO, pure coordination** → **ROPE** (Maintain, refine)
- **YES, hybrid structure** → **TANGLED ROPE** (Reform: preserve coordination, cut extraction)

### Test D: Power Maintenance
**Question:** Requires active enforcement? Alternatives suppressed? Who benefits?
- **YES** → **SNARE** (Expose, resist, exit if possible)
- **NO** → Continue to Test E

### Test E: Temporal Limitation
**Question:** Explicit sunset clause? Designed for transition?
- **YES** → **SCAFFOLD** (Use temporarily, dismantle when done)
- **NO** → Continue to Test F

### Test F: Obsolescence Check
**Question:** Maintenance cost > benefit? Function lost? Persists through inertia?
- **YES** → **PITON** (Bypass or eliminate)
- **NO** → **UNCLASSIFIED** (Gather more information or reconsider indices)

---

## Step 3: Avoid Common Misclassifications

| Error | Pattern | Cost | Fix |
|-------|---------|------|-----|
| **False Mountain** | Calling Snare unchangeable | Surrender to changeable injustice | Check: Who benefits from this claim? |
| **False Snare** | Calling Mountain constructed | Waste energy fighting reality | Check: Does reality enforce this? |
| **Snare as Rope** | Defending extraction as coordination | Legitimize harm | Check: Is benefit actually reciprocal? |
| **Tangled Rope as pure** | Treating hybrid as simple | Maintain extraction OR destroy coordination | Check: Can functions be separated? |

## Step 4: Strategic Response Decision

**Classification → Information**
**Values → Action**

Same classified constraint, different responses based on values:

**Example: Carbon credits classified as Tangled Rope [moderate/biographical/constrained/national]**
- Reformist: Preserve price signal, cut financial rents
- Revolutionary: Replace with direct regulation
- Conservative: Accept extraction as coordination cost
- Pragmatist: Use while building alternative

**The framework provides the map. You choose the route based on:**
- Your values (what matters most?)
- Your resources (what can you spend?)
- Your risk tolerance (what can you lose?)

## Critical Reminders

**Power-scaling matters:** Same constraint experienced differently by position
- Powerless: Extraction amplified (Snare feel)
- Moderate: See both functions (Tangled Rope)
- Institutional: Extraction reduced (Rope feel)

**Discomfort ≠ Damage:**
- Discomfort: Subjective reaction (fear, awkwardness)
- Damage: Objective harm (physiological, structural)
- Test edges to know the difference

**Some tensions are structural:**
- Autonomy vs. Connection
- Security vs. Growth
- Present vs. Future
- These are **overhangs to traverse**, not problems to solve
- Contain them, don't force resolution

---

## Energy Allocation Heuristics

**Maximum waste:** Fighting Mountains or maintaining Pitons

**High leverage:** Reforming Tangled Ropes or resisting Snares (if you have power to exit)

**Maintenance:** Preserving functional Ropes

**Growth:** Using Scaffolds temporarily without letting them calcify

---

## When This Manual Fails You

**If classification is ambiguous:**
1. Gather more information (especially about beneficiaries, enforcement, alternatives)
2. Test edges carefully (distinguish discomfort from damage)
3. Check your index specification (are you clear on WHO/WHEN/WHERE/HOW_MUCH?)

**If you're stuck between two categories:**
- Mountain vs. Snare: Check reality enforcement vs. power enforcement
- Rope vs. Tangled Rope: Check if extraction can be separated from coordination
- Tangled Rope vs. Snare: Check if genuine coordination core exists
- Scaffold vs. Rope: Check for explicit sunset clause or temporal limitation

**If the framework becomes analysis paralysis:**
- You're treating classification as a Clarity Fetish
- Make provisional classification, act, update based on evidence
- Perfect indexing is not a precondition for movement

## Quick Reference: The Six Categories

| Category | One-Line Test | Action |
|----------|---------------|--------|
| **Mountain** | Reality enforces (not humans) | Accept, route around |
| **Rope** | Coordination, low extraction | Maintain, refine |
| **Tangled Rope** | Coordination + extraction hybrid | Reform (preserve/excise) |
| **Snare** | Power-maintained extraction | Resist, exit, expose |
| **Scaffold** | Temporary with sunset | Use then dismantle |
| **Piton** | High cost, no benefit | Bypass, eliminate |
