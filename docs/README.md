# Intellectual Lineage

This directory contains the predecessor frameworks and protocols that Deferential Realism evolved from. These documents show the conceptual ancestry of the current framework.

## Documents

### [omega_variables.md](omega_variables.md) (~1,200 words)
**Framework for Identifying Reasoning Blockers**

The Omega Variables framework identifies three types of dependencies that block reasoning:

| Type | Block | Resolution |
|------|-------|------------|
| **Ω_E** (Empirical) | Missing observable data | Measurement, experiment, calculation |
| **Ω_C** (Conceptual) | Ambiguous terms/definitions | Explicit definition, framework selection |
| **Ω_P** (Preference) | Value disagreements | Decision by stakeholders |

This framework is used throughout DR to mark uncertainty sources and route them to appropriate resolution mechanisms.

### [indexical_relativity.md](indexical_relativity.md) (~100 words)
**Core Innovation Origin**

The foundational insight that constraint classifications are relative to observer position:
- WHO (agent power level)
- WHEN (time horizon)
- WHERE (exit options)
- HOW_MUCH (spatial scope)

Key distinction: This is NOT relativism (all opinions equally valid). Each indexed claim is objectively true or false within its specified index.

**Example:** The Medieval Church is simultaneously:
- Mountain (for a serf—cannot be changed)
- Noose (for a historian—extractive structure)
- Rope (for the Pope—coordination mechanism)

All three are objectively correct from their respective indices.

### [mck_v1.6.md](mck_v1.6.md) (~750 words)
**Verified Kernel Protocol**

A meta-cognitive protocol for grounded multi-perspective analysis:
- **Grounding protocol** - Distinguish observable from constructed
- **Multi-perspective mandate** - Analyze from multiple indices
- **Confidence calibration** - Explicit uncertainty quantification
- **Omega variable marking** - Flag unresolved dependencies
- **Dignity and reality invariants** - Ethical constraints on analysis

### [uke_protocol_framing_guide.md](uke_protocol_framing_guide.md) (~900 words)
**Routing vs. Truth Clarification**

Explains the UKE (Universal Knowledge Evaluator) metrics:
- UKE metrics are **routing mechanisms**, not truth measurements
- They create decision interfaces for consistent comparison
- Protocol triggering based on confidence thresholds
- Distinguishes "which path to take" from "what is true"

### [debugging_philosophy.md](debugging_philosophy.md) (~40KB)
**Predecessor Framework for Reasoning Error Identification**

The comprehensive predecessor to Deferential Realism:
- Systematic approach to identifying reasoning errors
- Error taxonomy (logical, evidential, motivational, structural)
- Correction protocols for each error type
- Bridge between abstract philosophy and practical debugging

This document shows how DR emerged from attempts to systematically debug philosophical reasoning.
